Detailed Description

Interactive map display widget with async layer compositing.

Rendering pipeline (Direct mode)

viewport change / layer change
→ 10 ms debounce timer (mDebounceTimer)
→ QtConcurrent::run( composite all visible layers )
→ QFutureWatcher::finished → swap mPixmap → update()
GrassMapCanvas::layers
const QList< GrassMapLayer * > & layers() const
Read-only access to the layer stack (bottom = index 0, top = last).
Definition grassmapcanvas.h:103

During a pan drag the last good mPixmap is shifted in paintEvent so the UI stays live. A new render is scheduled when the drag ends.

Coordinate system

The viewport is described by a GrassExtent (geographic rectangle in the native CRS of the GRASS location). mCenter holds the geographic centre point and mPixelsPerUnit holds the scale factor (pixels per map unit).

See also
GrassMapLayer, GrassLayerPanel, GrassDisplayDriver
