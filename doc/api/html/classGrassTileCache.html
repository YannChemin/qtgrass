Detailed Description

Thread-safe in-memory and on-disk cache for XYZ tile images.

Thread safety

  • get() — safe to call from any thread (acquires a read lock).
  • put() — safe to call from any thread (acquires a write lock).
  • clearMemory() — call from the main thread only.

Disk layout

Tiles are stored at:

~/.cache/qtgrass/tiles/<providerId>/<z>/<x>/<y>.jpg
