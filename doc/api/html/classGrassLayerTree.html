Detailed Description

QTreeView for the layer stack with drag-drop, visibility, and context menus.

Integrates GrassLayerTreeModel and GrassLayerDelegate. Context menus provide per-layer actions: zoom, properties, colour table, attribute table, build overviews, and remove.

Visibility toggles update the canvas via GrassMapCanvas::setLayerVisible(); opacity changes update the layer directly and schedule a re-render.

See also
GrassLayerTreeModel, GrassLayerDelegate, GrassLayerPanel
