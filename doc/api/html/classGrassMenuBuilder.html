Detailed Description

Static builder that populates a QMenuBar from GRASS's menudata.xml.

Reads $GISBASE/gui/wxpython/xml/menudata.xml and creates a menu tree matching the wxGUI layout. Each <menuitem> with a <command> tag triggers moduleCallback with the command string when activated. Items with a known <handler> name call the corresponding entry in handlerMap.

Two index maps are filled during build():

  • prefixMap — maps the module prefix (e.g. "r.", "v.") to the QMenu that hosts commands in that family.
  • commandActions — maps a full command name to the menu and action that represent it, enabling addon menus to insert numbered variants (e.g. "i.atcorr2") immediately after the base module's action.
