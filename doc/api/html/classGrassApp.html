Detailed Description

Main window of the qtgrass application.

Hosts the full GRASS GUI: module toolbox on the left, a layer panel and map canvas in the centre, and a notification bar at the top. Layout:

┌──────────────────────────────────────────────────┐
│ GrassMessageBar (hidden when empty) │
├────────────────┬─────────────────────────────────┤
│ GrassToolbox │ GrassLayerPanel │ GrassMapCanvas│
│ (module tree) │ (layer list) │ (map display) │
└────────────────┴─────────────────────────────────┘
│ Status bar: coordinates / location │
└──────────────────────────────────────────────────┘
