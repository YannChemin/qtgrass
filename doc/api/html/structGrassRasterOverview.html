Detailed Description

One pre-built overview level for a raster map.

Overviews are created by the user via the layer context-menu "Build Overviews" action, which calls cascaded r.resamp.stats runs. They live as sibling maps in the same mapset under names generated by qtgrass and recorded in cell_misc/<mapname>/qtgrass_ovr.
