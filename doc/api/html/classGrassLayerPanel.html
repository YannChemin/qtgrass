Detailed Description

Outer container for the layer management panel.

Hosts a GrassLayerTree (top section) and a GrassDecorationPanel (bottom section). All canvas-state changes (add/remove/reorder layers, visibility, opacity) are mediated through this class so callers do not need to interact with the tree or canvas directly.

See also
GrassLayerTree, GrassDecorationPanel, GrassMapCanvas
