Detailed Description

Manages a GRASS vector editing session with undo/redo.

Wraps the GRASS C vector edit API (Vect_open_update(), Vect_write_line(), Vect_delete_line(), Vedit_snap_point(), Vedit_split_lines()) and records each mutating operation as a QUndoCommand so edits can be undone.

All coordinates are in GRASS map units (geographic coordinates). The caller is responsible for converting viewport pixels to map coordinates before calling any geometry method.

Session lifecycle

GrassVectorEditor ed;
ed.open( "roads", "PERMANENT" ); // opens for update or creates new
ed.addLine( points ); // write + push undo command
ed.undoStack()->undo(); // revert last operation
ed.close( true ); // rebuild topology + close
