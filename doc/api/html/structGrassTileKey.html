Detailed Description

Identifies a single slippy-map tile by zoom level and tile coordinates.

Used as the key type in QHash-based tile caches. qHash() is provided so GrassTileKey can be used directly in QHash<GrassTileKey, …> containers.

See also
GrassTileCache, GrassTileFetcher
