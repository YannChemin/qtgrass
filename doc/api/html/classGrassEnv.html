Detailed Description

Manages the GRASS GIS session environment.

Wraps G_set_gisrc_mode() / G_no_gisinit() and the four core GRASS environment variables: GISBASE, GISDBASE, LOCATION_NAME and MAPSET.

Module mode (--qtui): the variables are already set by the calling GRASS session; init() just validates them.

Full-GUI mode: the startup wizard calls openMapset() once to establish the session, and again whenever the user switches mapsets.

Access the singleton via instance().

QProcessEnvironment GrassEnv::buildSubprocessEnv ( ) const

Build a QProcessEnvironment for child GRASS processes.

Writes a temporary GISRC file to /tmp/qtgrass_<pid>.gisrc from the current in-memory session and returns a QProcessEnvironment with GISRC pointing to it. Child processes call G_gisinit() which reads from GISRC, not from our in-memory state.

The file persists for the lifetime of the process and is safely reused across repeated subprocess calls.

Returns
Environment suitable for passing to QProcess::setProcessEnvironment().

◆ init()

bool GrassEnv::init ( )

Initialise from the process environment.

Reads GISBASE from the process environment and calls G_no_gisinit() to set up the GRASS C library without a GISRC file. Also verifies that the compile-time GRASS header version matches the runtime libgrass_gis version.

Returns
true on success; false if GISBASE is missing or the version check fails. Check lastError() for a human-readable message on failure.
