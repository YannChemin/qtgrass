Detailed Description

Parser for GRASS GIS workspace files (.gxw).

Reads only the fields used by qtgrass — the wxPython AUI layout blob and monitor-specific settings are silently ignored.

Usage:

GrassWorkspace ws;
if ( !ws.load( "/path/to/file.gxw" ) )
qWarning() << ws.lastError();
for ( const GwxDisplay &d : ws.displays() )
for ( const GwxLayer &l : d.layers )
canvas->addRasterLayer( l.name );
