Detailed Description

Panel for map decorations rendered via GRASS d.

  • display modules.

Lives at the bottom of the layer panel. Each decoration (legend, scale bar, north arrow, grid) has an enable/disable checkbox and a "…" settings button that opens a small configuration dialog.

Connect decorationsChanged() to GrassMapCanvas::setDecorations() so the canvas re-renders whenever a setting changes.

See also
GrassDisplayCmd, GrassMapCanvas::setDecorations()
