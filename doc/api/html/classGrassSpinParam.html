Detailed Description

Integer parameter widget (QSpinBox).

The mIsSet flag tracks whether the user has touched the field, so that a parameter at its default value contributes nothing to the command line.

Returns true when the widget holds a valid, acceptable value.

For optional parameters this is always true. For required ones it checks that the field is non-empty. Subclasses override as needed.
