Detailed Description

Fetches XYZ tiles over HTTP and stores them in a GrassTileCache.

Thread requirements

Must live on the main (GUI) thread — owns a QNetworkAccessManager. Call fetchTile() via Qt::QueuedConnection from render threads.

Request deduplication

Calling fetchTile() for a tile that is already in-flight or already cached is a no-op. At most maxParallel (default 6) requests are in flight simultaneously; additional requests are queued.

Signals

Connect tileFetched() to GrassMapCanvas::scheduleRender() so the canvas repaints as each tile arrives.

See also
GrassTileCache, GrassTileBackground
