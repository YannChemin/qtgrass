Detailed Description

Abstract base class for anything the map canvas can render.

Concrete subclasses implement extent() and render() to produce a QImage for a given viewport rectangle and pixel size.

Per-layer image cache

render() should call cacheHit() on entry and return cachedImage() on a hit. On a miss it should compute a new image, call storeCache(), and return the image. The cache is invalidated explicitly via invalidateCache() when the layer data changes on disk, and implicitly on every viewport change (a cache miss via cacheHit()).

See also
GrassRasterMapLayer, GrassVectorMapLayer, GrassTileBackground
