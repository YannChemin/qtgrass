Detailed Description

Renders a GRASS vector map using the GRASS C Vector API.

Geometry (lines, areas, points) is loaded once from disk via the GRASS C API and cached as geographic-coordinate QPolygonF collections. render() then reprojects these to viewport pixels on every call, enabling fast re-renders after pan/zoom without re-reading the map.

A sigsetjmp crash guard wraps Vect_open_old() to survive corrupt topology files (such maps should be rebuilt with v.build).

GrassVectorStyle, GrassMapLayer
