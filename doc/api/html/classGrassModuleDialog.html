Detailed Description

Dialog for running any GRASS module via its --interface-description XML.

Opened when a module is invoked through the module toolbox or via --qtui on the command line.

Tab layout

  • One tab per <guisection> defined by the module XML.
  • A catch-all Required tab for mandatory parameters with no section.
  • A Command tab showing a live preview of the constructed command line.
  • An Output tab streaming QProcess stdout / stderr.
  • A Manual tab displaying the module's HTML help page.

Buttons

Run — validates required fields, then starts the module as a QProcess.

Copy Command — copies the current command line to the clipboard.

Close — available at all times; kills a running process if needed.

See also
GrassParamWidget, GrassFlagWidget, GrassXmlParser
