Detailed Description

Descriptor for one d.

  • GRASS display module invocation.

GrassDisplayDriver accepts an ordered list of GrassDisplayCmd objects and runs them sequentially to composite layers and decorations into a single map image.

Convenience factory functions (raster(), vector(), legend(), barscale(), northarrow(), grid()) cover the most common use cases.

See also
GrassDisplayDriver, GrassMapCanvas::buildDisplayCmds()
