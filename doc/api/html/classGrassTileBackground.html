Detailed Description

Renders slippy-map XYZ tiles as the bottom-most canvas layer.

Provides satellite, street-map, and terrain backgrounds sourced from any XYZ tile provider (Google, Bing, OpenStreetMap, …).

Thread safety

Tile fetching is async — GrassTileFetcher runs on the main thread and delivers tiles to GrassTileCache (thread-safe). render() reads the cache from the render thread and queues missing fetches via QMetaObject::invokeMethod (Qt::QueuedConnection).

Projected CRS support

For geographic CRS locations the tiles are pasted directly (Web Mercator tiles match lat/lon closely at large scales).

For projected CRS locations each tile's four corners are reprojected from EPSG:4326 to the location CRS via a thread-local PROJ 9 transform, and the tile image is warped onto the viewport using QTransform::quadToQuad().

See also
GrassTileCache, GrassTileFetcher, GrassMapCanvas
