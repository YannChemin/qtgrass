Detailed Description

Abstract base for all parameter input widgets in GrassModuleDialog.

Each concrete subclass handles one GRASS parameter type (string, integer, float, file, enum). The factory function create() selects the appropriate concrete class from the GrassParamDesc descriptor.

See also
GrassLineEditParam, GrassFileParam, GrassEnumParam, GrassSpinParam, GrassDoubleSpinParam, GrassModuleDialog

bool GrassParamWidget::isValid ( ) const
virtual

Returns true when the widget holds a valid, acceptable value.

For optional parameters this is always true. For required ones it checks that the field is non-empty. Subclasses override as needed.
