Detailed Description

Renders a GRASS raster map using the GRASS C API.

Rendering approach: the GRASS window is set to the exact viewport resolution (G_set_window()), then one scanline per output row is read via Rast_get_d_row() and converted to ARGB. This matches the behaviour of d.rast in the wxPython GUI.

Overview selection: before rendering, selectOverviewMap() picks the finest pre-built overview level whose resolution is still coarser than the current output resolution, giving proportional speedup for zoomed-out views without a GeoTIFF export step.

See also
GrassRasterOverview, GrassMapLayer
