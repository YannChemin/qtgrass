Detailed Description

Compatibility interface for ported QGIS GRASS plugin objects.

Replaces QgisInterface* from the QGIS plugin architecture so that ported code (QgsGrassModule, QgsGrassTools, …) can be compiled without any QGIS runtime dependency.

Only the four methods actually called by the ported GRASS plugin code have real implementations. All others would be no-op stubs and are not exposed here.
